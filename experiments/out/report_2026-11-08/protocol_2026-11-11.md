# Evaluation protocol for the benchmark suggester, version 1 (frozen 11 November 2026)

Purpose. Fix every prompt, rule and procedure used to compare the tool with the model alone, so that the next paper sample is a held-out test and not development data. The three sets used so far (old 2018-2021, post-cutoff a and b) informed the tool's tier, the truth-list procedure, the scoring overrides and the age split, and are development data under this protocol. Any change to a file in the manifest is a new protocol version and must be declared before a held-out sample is drawn. protocol_manifest.json lists sha256 per file in two parts: as_run (the tool source that produced the current numbers, snapshot/src, and the experiments scripts as shipped) and v2_untested (the working-tree tool source with the version-2 changes, which has produced no number). It is regenerated at every package build so the hashes match the supplied files.

## 1. Systems compared

- Tool. researchreadernerd pipeline: plan (field, themes, queries) -> literature search (the paper's reference list from OpenAlex, up to 60; co-usage; bibliographies of related papers; catalogs) -> model proposals (up to 15 names with the title of the paper that introduced each; a proposal is kept only if OpenAlex has that source paper) -> evidence ranker picks 10 from the whole pool -> final 10 = the first 5 confirmed proposals in the model's order, then the ranker's picks in rank order, skipping duplicates. Constants: SUGGESTIONS 10, RESERVED_PROPOSALS 5, RECENT_SLOTS 0, MAX_REFERENCES 60, MONTHS_BEFORE 6 (a benchmark known only from citing papers must have existed six months before the paper). Model claude-haiku-5-5 at effort medium for plan, propose and rank, low for extraction; prompts in src/researchreadernerd/analyze.py.
- Model alone. claude-haiku-5-5, LLM_ONLY_PROMPT (experiments/ablation.py): given the same input as the tool's user, name up to 10 public benchmarks, no literature search.
- Judge. claude-haiku-5-5 at effort low, MATCH_PROMPT (experiments/benchmark_eval.py): for each truth benchmark, the one suggestion that is the same benchmark, allowing spelling, version and subset variants; cached per (paper, run); re-judged when the truth list changes. Hand-rejected matches in experiments/match_overrides.json score as misses in every test.

Every number in a report comes from one tool version; a changed tool means every row is re-run.

## 2. Paper sampling

Script experiments/sample_2026.py, seed 7. OpenAlex filter: arXiv preprints (source S4306400194), primary field Computer Science (fields/17), publication date within the stated window, referenced_works_count > 15, has_abstract; a random sample of 150 from OpenAlex (its seeded sample), scanned in order; a paper is taken if its abstract is at least 300 characters and its primary topic has fewer than 3 papers taken already; stop at 30. The window for a post-cutoff set must start after the model's training cutoff (June 2026 for Haiku 5.5). Papers whose PDF cannot be read (over 24 MB, or arXiv withdrawn) are replaced before any run by the next eligible paper in the scan, and the swap is recorded (papers_<set>_swaps.json). Papers already in an earlier set are excluded (--exclude). A paper with no public benchmark in its truth list is read but not scored; the count of such papers is reported.

## 3. Truth lists

- Extraction: the tool reads the PDF (claude-haiku-5-5) and lists the benchmarks used with a task per entry; the judge groups entries into named benchmarks with aliases and a kind: public, own, metric, composite, not_a_benchmark, not_evaluated. Only kind public is scored.
- Definition of public (predeclared 12 November, tightened the same day): a benchmark counts as public when the paper reports a result on it (a table, figure or numbered result) and the benchmark was publicly available before the paper. Availability and authorship are separate: a dataset released earlier by the paper's own authors qualifies, and a citation to an external paper does not by itself establish availability. Availability is shown by an independent release that predates the paper (a dataset repository, download page, leaderboard or code release with a date) or by a published or preprint source paper that itself releases the benchmark. A benchmark first released with or after the paper, or named with no citation and no locatable release, is own. Related-work mentions, training-only data, pre-training sources and analysis-only uses do not count. A composite is scored as its components.
- Unresolved cases: where the evidence (the paper, its citations, and a search for a dated release) cannot settle availability, the entry stays in the denominator as public, is listed by name in the report, and the headline is given with and without those entries (the stated sensitivity). Nothing is dropped without that listing. Cases open at the time of this declaration: EmulatorBench, PMPP-Hard and MazeBench in Prime Agent (2608.23552) and the Mental Health Multimodal tabular set in MERID (2609.36235); each is settled by the rule above, with the decision recorded in the entry's hand_check record, before the next run.
- Check: every scored paper is checked against its PDF before scoring. Procedure as on 11 November: a checking model reads the PDF against the list and returns, per entry, a verdict (keep, rekind, rename, remove, split, unclear) with a quoted location, plus missed public benchmarks; a reviewer compares every non-keep verdict with the extracted snippet and the PDF and applies only verdicts with a location. Removals without a location are not applied. Each entry carries a hand_check record; the pre-check list is kept.
- Years: each public entry carries an introduction year with its source, in this order of preference: the benchmark's own paper on arXiv (first version date), the paper's citation year for it, the earliest source paper in the tool's evidence, a hand assignment with a cited source (years_manual.json), the model's memory last. Earliest documented release wins over venue year. A checking model's year from memory is never adopted.

## 4. Tests

- User 1 (author): input title and abstract. Conditions: refs+model (the paper's reference list fetched from OpenAlex by title, plus proposals) is the product as run; topic+model (topic search instead of the reference list) is the like-for-like condition against the model alone, which gets title and abstract only. Both reported.
- User 1' (leave-one-out): the tool has read the whole paper; one public benchmark at a time is removed from everything it read (its entry, every mention of its names in summary and method, every reference whose title is its source paper or names it); the tool runs in manuscript mode with citing papers withheld and OpenAlex lookups limited to the paper's publication year; the model alone gets the same scrubbed description (the 'used' part of the ranker input). Recovered = the removed benchmark is in the 10.
- Memory probes: title only, declining allowed (does the model say it knows the paper, and what does it name); forced (name 10 anyway). Reported by benchmark age.
- Leak checks (experiments/leak_check.py) on every leave-one-out run: no name or alias of the withheld benchmark in the ranker input; the paper's own record not read back as evidence for the withheld benchmark. These cover remnant names and target self-evidence only; same-year indirect evidence (lookups are limited by year, not month) and judge errors are not covered and are stated as such.

## 5. Scoring and reporting

- Per benchmark: in pool (the ranker saw a matching candidate), in final 10, in the ranker's own 10 (ranker only), and, for user 1', in the 10 of the model alone. Family matching by the judge is the primary rule; exact matching (suggestion equals the truth name or an alias after normalisation) is reported beside it as a sensitivity.
- Intervals: 90% Wilson over benchmarks; 90% percentile bootstrap over papers (10,000 rounds, seed 7). The comparison between the two systems is the paired difference (model alone minus tool) bootstrapped over papers. Primary estimand (predeclared 12 November): benchmark-weighted, hits pooled over the resampled papers' benchmarks, matching the recall figures in every table. The paper-weighted estimand, the mean over papers of each paper's own difference, is reported beside it in every comparison; where the two verdicts differ, both are stated. Overlapping single-system intervals are not read as parity.
- Age bins by introduction year: 2024 or earlier, 2025, 2026 (relative to Haiku 5.5's cutoff; a later model shifts the bins). Both the pooled number and the age split are reported.
- Scripts: benchmark_eval.py score, leave_one_out.py score, loo_llm.py, memory_probe.py, memory_probe_forced.py, age_split.py, match_sensitivity.py, combined_report.py. Every table is regenerated from the per-benchmark rows; no number is typed by hand.

## 6. Held-out rule

A held-out sample is drawn only after this protocol and the tool version are fixed, with the window, size and seed stated in advance. Nothing in the manifest changes between the draw and the report. If a change is needed, the sample becomes development data and a new sample is drawn under the new version. Predictions recorded before the next draw, from the development sets (post-cutoff a+b, 159 benchmarks): model alone ahead on benchmarks introduced by 2024 on both tests; tool ahead on the leave-one-out for benchmarks introduced in 2025; neither above 50% on 2026 benchmarks; tool's final 10 within 10 points of the model alone on user 1 and within 6 on user 1'.

## 7. Costs and approvals

A post-cutoff sample of 30 papers costs about $2.50 of OpenAlex for user 1 and leave-one-out runs plus Haiku calls; a candidate-dating pass about $5 per 60 papers. No paid run is started without the group's agreement once this protocol is in force.

Manifest: protocol_manifest.json (as_run and v2_untested parts; regenerated at each package build). Source snapshot behind the current numbers: snapshot/src in the package.

## 8. Proposed version 2 of the tool (Ayush, 11 November; for the group's agreement)

Lock, for the held-out sample, the tool with three changes to the pipeline in section 1, everything else unchanged:

1. Ranking call by claude-sonnet-5-5. One call per run; plan, reading, proposals and the judge stay on Haiku. Offline evidence on the development sets (sonnet_rerank.md): +7 and +5 points for the ranker alone over Haiku's ranking on user 1 and user 1', +3 and +4 for the final 10 with the tier; gain concentrated in benchmarks introduced in 2025; no change for 2026.
2. Candidate dating with a recency rule. After the pool is built, every candidate without an introduction year gets one: Haiku names the source paper, OpenAlex confirms it and gives the year (the proposal step's confirmation, applied to the pool; about 50 lookups per run). The ranker then sees each candidate's year with the instruction not to hold thin evidence against a benchmark introduced within a year of the paper. Reserved slots for recent candidates stay at 0 unless the development test shows they add to the discount. Untested as of this version; the 10 November slot rule without dating lowered recall and was reverted.

3. The paper's own arXiv bibliography. find_paper reads the paper's arXiv HTML bibliography and looks up by title, in OpenAlex, every entry OpenAlex had not linked (at most 40 per paper); the resolved works join the reference list ahead of the cap. Motivation: of the 12 pool misses from 2026, 4 are confirmed cited-but-unlinked (OBLIQ-Bench, ManyIH Coding and IF, FeatureBench) and 2 more probable; the leave-one-out withholding filter applies to the merged list. Cost: one arXiv fetch and up to 40 OpenAlex title searches per run. Untested.
A second proposal call for subfield datasets was also built and is switched off by default; it is not part of version 2.

Order of work, so the lock is on a tested tool:
- Build both changes (ranking-model setting; dating pass; year shown to the ranker).
- Development test on the existing post-cutoff sets: dating offline on the cached pools first (about $5 of OpenAlex, no pipeline run), then, if the recent rows improve without the older rows falling, one live run of user 1 and leave-one-out on the 60 papers and the old set with the version-2 tool (about $4 of OpenAlex). Decision rule: adopt the rule if the 2025-2026 rows gain at least 10 points on user 1' and the 2024-or-earlier rows lose at most 3; otherwise lock Sonnet alone.
- Regenerate the manifest as version 2, record predictions, then draw the held-out sample (30 papers, window November-December 2026 or later, seed stated at the draw; about $2.50 plus the dating lookups, about $4).
